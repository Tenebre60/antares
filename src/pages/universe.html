Spaces Orbits Missions Ler depois

Spaces separam suas abas por contexto. Cada Space guarda as próprias abas; troque de Space na barra superior ou com Ctrl+Alt+1…9. Arraste uma aba até o nome de uma Space para movê-la.

Orbits são grupos de páginas salvos para abrir de novo de uma vez — por exemplo, tudo o que você usa para um projeto. Salve as abas da Space atual como uma Órbita.

Missions são objetivos com tarefas, anotações e as páginas que você precisa para cumpri-los. Use o botão de bandeira na barra para adicionar a página aberta a uma missão.

Páginas guardadas com o botão “Ler depois” da barra de ferramentas.
